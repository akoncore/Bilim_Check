# Bilim Check

Қазақ тіліндегі математика диагностикасы. Оқушы аты-жөні мен сыныбын енгізеді, есептерді шығарады және нәтижесін көреді. Мұғалім кабинетінде тіркелген оқушылар, тест тарихы, басталу және аяқталу уақыты, әр есептің жауабы мен тексеру нәтижесі көрсетіледі.

## Windows-та іске қосу

Python 3.12 жеткілікті. PowerShell ішінен:

```powershell
$env:ADMIN_PASSWORD = Read-Host 'Мұғалім құпиясөзі' -MaskInput
python app.py
```

- Оқушы беті — [http://127.0.0.1:8000/](http://127.0.0.1:8000/)
- Мұғалім кабинеті — [http://127.0.0.1:8000/admin/](http://127.0.0.1:8000/admin/)
- Жазбалар `data/school.sqlite3` файлында сақталады. `DB_PATH` арқылы файл орнын ауыстыруға болады.
- Оқушының кіруі сол браузердің cookie файлы арқылы сақталады. Жүйеден шыққан соң қайта тіркелу жаңа оқушы жазбасын жасайды.

## Диагностика қалай жұмыс істейді

- Оқушы сыныбы кіретін бөлімдерге қатыса алады. 9-сынып екі бөлімнің бірін таңдай алады. 7-сыныпқа «5–9» бөлімі 5, 6 және 7-сынып есептерін береді.
- Әр сыныптан үш тақырып таңдалады. Әр тақырыпта 2–3 есеп болады. Тақырыпта кемінде екі есеп болуы қажет.
- Жауап белгіленген сәтте сақталады. Бетті қайта ашқанда тестті жалғастыруға болады. Мұғалім аяқталмаған тестті де тізімнен аша алады.
- Сынып бойынша барлық есеп бағаланып, дұрыс жауап 70%-дан төмен болса, сол сыныпты қайталау ұсынылады. Бірнеше сынып осы межеден төмен болса, ең төменгі сынып көрсетіледі. Мысалы, әр сыныпта 6 есептің 5-еуі дұрыс болса, 70% межесінен өтеді.
- Жинақта 33 тақырып пен 66 үлгі есеп бар. Оқу бағдарламасына сай өз есептеріңізді мұғалім кабинетінен қосуға болады.

## Жауаптары бар есептерді енгізу

Мұғалім кабинеті → **Есептер банкі** → **Импорттау**. UTF-8 JSON файлын жүктеңіз. Дайын толық үлгі — `question-bank.json`.

```json
{
  "questions": [
    {
      "id": "grade-6-rational-03",
      "grade": 6,
      "topic": "Рационал сандар",
      "prompt": "−8 + 3 = ?",
      "options": ["−11", "−5", "5", "11"],
      "correct_index": 1
    }
  ]
}
```

`correct_index` — дұрыс жауаптың орны. Бірінші нұсқа — 0, екінші — 1, үшінші — 2. Мысалда оқушы «−5» таңдаса, сервер оны дұрыс деп есептейді. Әр есепке жеке `id` беріңіз. Бірдей `id` қайта жүктелсе, есеп жаңарады. Импортқа кірмеген есептер сақталады. Жаңа тақырып қосқанда атауын бірдей жазып, кемінде екі есеп беріңіз. Әр есеп 2–6 жауап нұсқасын қабылдайды. Бір файлға 2000 есепке дейін, жалпы 2 МБ шектеу қолданылады. Бұрын басталған тесттер есептердің өз нұсқасын сақтайды.

## API

Барлық жазу сұраулары `application/json` қабылдайды. Оқушы және мұғалім сеанстары бөлек cookie арқылы басқарылады.

| Әдіс | Жол | Мақсаты |
|---|---|---|
| POST | `/api/login/` | `name`, `grade` арқылы оқушыны тіркеу |
| GET | `/api/home/` | Рұқсат етілген бөлімдер және тест күйі |
| POST | `/api/test/` | `band` бойынша тест бастау немесе жалғастыру |
| GET | `/api/test/<id>/` | Есептерді және сақталған белгілерді алу |
| POST | `/api/test/<id>/answer/` | `question_id`, `selected` сақтау |
| POST | `/api/test/<id>/finish/` | Тестті аяқтау |
| GET | `/api/test/<id>/result/` | Оқушының қорытындысы |
| POST | `/api/admin/login/` | Мұғалім құпиясөзімен кіру |
| GET | `/api/admin/results/` | Нәтижелер |
| GET | `/api/admin/students/` | Оқушылар, `q` арқылы іздеу |
| GET | `/api/admin/student/<id>/result/` | Бір оқушының тест тарихы |
| GET | `/api/admin/results/<id>/` | Бір тесттің толық талдауы |
| POST | `/api/admin/questions/import/` | Есептерді импорттау |

Тізімдер `page` және `page_size` параметрлерін қабылдайды. Әдепкісі — 20 жазба, ең көбі — 100. Тақырыптар тізімі банк нұсқасы бойынша кэштеледі. Жазу сұраулары минутына IP бойынша шектеледі: мұғалім кіруі 10, оқушы тіркелуі 30, қалған жазу сұраулары 240.

## Docker, Nginx және домен

1. VPS-ке Docker Compose және Certbot орнатыңыз. Кодты `/opt/bilim-check` ішіне орналастырыңыз.
2. Доменнің DNS A жазбасын VPS IP мекенжайына бағыттаңыз. IPv6 қолдансаңыз ғана AAAA жазбасын қосыңыз. 80 және 443 порттары қолжетімді болуы керек.
3. `.env.example` файлын `.env` ретінде көшіріп, `ADMIN_PASSWORD` және нақты `DOMAIN` мәндерін жазыңыз. `HTTP_PORT=80` күйінде тұрады.
4. Сертификат алып, HTTPS конфигурациясын қосыңыз:

```bash
cd /opt/bilim-check
mkdir -p deploy/acme
docker compose up -d --build --wait
sudo certbot certonly --webroot -w /opt/bilim-check/deploy/acme -d diagnostic.example.kz
docker compose -f compose.yaml -f compose.https.yaml up -d --wait
curl --fail https://diagnostic.example.kz/health
```

Мысалдағы доменді нақты доменмен ауыстырыңыз. Certbot жаңартқан соң Nginx-ті қайта жүктеу үшін жаңарту ілмегін `/etc/letsencrypt/renewal-hooks/deploy/` астына орнатыңыз. Ілмек командасы:

```bash
cd /opt/bilim-check
docker compose -f compose.yaml -f compose.https.yaml exec -T nginx nginx -s reload
```

SQLite деректері `records` Docker томында сақталады. Жұмыс істеп тұрған дерекқорды көшіргенде SQLite онлайн backup API құралын қолданыңыз. Сайт бір VPS пен бір қолданба контейнеріне арналған.

## GitHub Actions және тексеру

`.github/workflows/ci.yml` әр push және pull request үшін Python тесттерін, JavaScript синтаксисін және Docker/Nginx іске қосылуын тексереді. VPS-те HTTPS қолмен алғаш рет іске қосылған соң, GitHub-та `DEPLOY_ENABLED=true` repository variable мәнін қосыңыз. `production` ортасына `DEPLOY_HOST`, `DEPLOY_USER`, `DEPLOY_KEY`, `DEPLOY_KNOWN_HOSTS` құпияларын енгізіңіз. SSH пайдаланушысының `/opt/bilim-check` ішіне жазу және Docker Compose іске қосу құқығы қажет. CD негізгі тармақта тек CI өткеннен кейін іске қосылады.

```powershell
python -m unittest discover -s tests -v
Get-Content -Raw web/app.js | node --check
```
